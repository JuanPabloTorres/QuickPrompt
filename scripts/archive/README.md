# Herramientas históricas desactivadas

`Restructure-Folders.ps1.disabled` es el script de reorganización antiguo de
MAUI. Se conserva íntegro por trazabilidad, con extensión no ejecutable: sus
rutas y movimientos corresponden a la raíz anterior y no deben usarse en la
estructura actual. No forma parte del arranque, pruebas ni composición de NOVA.
