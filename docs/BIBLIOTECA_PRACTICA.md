# Biblioteca práctica de QuickPrompt

60 prompts en 20 colecciones. Abre una colección, elige una tarea y completa los campos con tus datos. Son instrucciones reutilizables, no respuestas inventadas.

## Correos y comunicación

- **Escribir un correo profesional**: Para solicitar algo, informar o responder en el trabajo.
- **Responder un mensaje difícil**: Para poner límites o resolver un desacuerdo sin escalarlo.
- **Mejorar un texto sin cambiar su sentido**: Para convertir un borrador en un mensaje claro.

## Organización y productividad

- **Organizar mi día con prioridades reales**: Para pasar de una lista desordenada a un plan posible.
- **Convertir una reunión en acuerdos**: Para extraer decisiones y pendientes de notas o transcripciones.
- **Desbloquear una tarea que estoy postergando**: Para encontrar una primera acción pequeña y realizable.

## Estudio y aprendizaje

- **Entender un tema con ejemplos**: Para aprender algo nuevo sin explicaciones innecesariamente técnicas.
- **Crear un plan de estudio alcanzable**: Para preparar un examen o aprender una habilidad.
- **Practicar preguntas de examen**: Para estudiar activamente y recibir correcciones.

## Programación

- **Encontrar la causa de un error de código**: Para depurar con evidencia y obtener una corrección mínima.
- **Revisar código antes de integrarlo**: Para detectar fallos reales y riesgos de mantenimiento.
- **Diseñar pruebas para una función**: Para cubrir comportamiento y regresiones, no solo líneas de código.

## Tecnología e inteligencia artificial

- **Entender un problema técnico paso a paso**: Para diagnosticar errores de una aplicación o equipo.
- **Comparar herramientas con criterios claros**: Para ordenar información antes de elegir una herramienta.
- **Mejorar una instrucción para una IA**: Para obtener un prompt preciso sin añadir complejidad innecesaria.

## Negocios y emprendimiento

- **Evaluar una idea de negocio sin inventar un mercado**: Para convertir una idea en hipótesis que puedas comprobar.
- **Redactar una propuesta para un cliente**: Para presentar un servicio con alcance y entregables claros.
- **Definir un proceso de trabajo sencillo**: Para documentar una tarea repetitiva y delegarla.

## Marketing y ventas

- **Escribir una descripción de producto que ayude a decidir**: Para explicar beneficios sin exageraciones ni promesas falsas.
- **Preparar una conversación de ventas consultiva**: Para comprender al cliente antes de ofrecer una solución.
- **Diseñar una campaña pequeña y medible**: Para pasar de una intención comercial a acciones concretas.

## Redes sociales

- **Crear publicaciones útiles para mi audiencia**: Para publicar contenido con una idea y propósito claros.
- **Convertir un contenido largo en publicaciones**: Para reutilizar material propio sin distorsionarlo.
- **Responder comentarios de clientes**: Para contestar reseñas y consultas con respeto.

## Empleo y entrevistas

- **Adaptar mi CV a una oferta sin inventar experiencia**: Para destacar experiencia verdadera que encaja con un puesto.
- **Practicar una entrevista de trabajo**: Para ensayar respuestas y recibir comentarios concretos.
- **Redactar una carta de presentación auténtica**: Para explicar por qué encajas en un puesto.

## Idiomas y traducción

- **Traducir conservando intención y tono**: Para traducir mensajes, documentos breves o publicaciones.
- **Practicar conversación en otro idioma**: Para aprender conversando a tu nivel.
- **Corregir un texto y aprender de los errores**: Para mejorar gramática y expresión sin perder tu voz.

## Documentos y políticas

- **Resumir un documento con sus límites**: Para extraer lo importante sin perder condiciones ni excepciones.
- **Comparar dos documentos o versiones**: Para encontrar cambios, contradicciones y preguntas pendientes.
- **Entender una política o un contrato en lenguaje claro**: Para organizar cláusulas y preparar preguntas de revisión.

## Datos y presupuesto

- **Crear una fórmula de Excel o una hoja de cálculo**: Para calcular o transformar datos con una fórmula comprobable.
- **Organizar un presupuesto con mis cifras**: Para ordenar ingresos y gastos sin recomendaciones de inversión.
- **Interpretar una tabla sin inventar causas**: Para encontrar patrones y límites en datos pequeños.

## Escritura creativa

- **Desarrollar una historia a partir de una idea**: Para transformar una premisa en una historia con conflicto.
- **Dar profundidad a un personaje**: Para crear personajes con decisiones y contradicciones creíbles.
- **Revisar una escena conservando mi estilo**: Para mejorar ritmo, claridad y tensión narrativa.

## Diseño y experiencia de usuario

- **Revisar una pantalla desde la tarea del usuario**: Para encontrar fricción real en una interfaz.
- **Escribir textos claros para una aplicación**: Para mejorar botones, formularios y mensajes de error.
- **Preparar una prueba de usabilidad**: Para observar si las personas pueden completar tareas.

## Vida cotidiana y cocina

- **Cocinar con lo que tengo**: Para obtener una receta sencilla usando ingredientes disponibles.
- **Preparar una lista de compras sin desperdiciar**: Para convertir comidas previstas en una compra organizada.
- **Comparar opciones para una decisión cotidiana**: Para ordenar una decisión sin que la IA decida por ti.

## Viajes y eventos

- **Preparar un itinerario a partir de datos verificados**: Para organizar un viaje y detectar qué debes comprobar.
- **Preparar el equipaje según mi viaje**: Para llevar lo necesario según actividades y restricciones.
- **Organizar un evento sin olvidar dependencias**: Para convertir un evento en un plan de tareas y responsables.

## Salud y bienestar

- **Preparar información para una consulta médica**: Para ordenar lo que quieres contar y preguntar en una consulta.
- **Organizar mi registro de actividad física**: Para revisar constancia y hábitos a partir de tus propios registros.
- **Ordenar pensamientos para hablar de una preocupación**: Para escribir lo que te ocurre y preparar una conversación de apoyo.

## Familia y crianza

- **Preparar una conversación familiar respetuosa**: Para hablar de un desacuerdo sin acusaciones.
- **Organizar responsabilidades en casa**: Para hacer visibles tareas y acordar un reparto realista.
- **Preparar una reunión con el colegio**: Para llevar ejemplos y preguntas concretas sobre un estudiante.

## Ocio y juegos

- **Crear una noche de juegos con mis recursos**: Para organizar una actividad de grupo sencilla.
- **Planificar cómo mejorar en un videojuego**: Para practicar una habilidad concreta sin trampas.
- **Crear un cuestionario para jugar en grupo**: Para preparar una actividad entretenida a partir de material conocido.

## Deportes y motivación

- **Analizar un partido a partir de mis notas**: Para separar observaciones de opiniones sobre un encuentro.
- **Convertir un objetivo en acciones pequeñas**: Para hacer concreto un objetivo personal sin promesas vacías.
- **Revisar mi progreso de la semana**: Para reconocer avances y ajustar el próximo paso.
