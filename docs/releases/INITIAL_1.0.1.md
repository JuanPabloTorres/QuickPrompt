# QuickPrompt 1.0.1 — versión inicial

Estado: preparación de integración; tag y promoción finales pendientes de aceptación.

La entrega reúne la aplicación web de cuentas, bibliotecas con variables,
colecciones, versiones e historial, permisos compartidos, correo Brevo, NOVA, MCP
y Companion con perfiles y protocolos explícitos. Conserva ambas historias Git.

Evidencia base: candidato conjunto aislado 19/20 con 28 llamadas reales a Qwen,
sin retries; backend 1857 PASS/2 omisiones opt-in. La continuación portable pasó
6 contratos HTTP, 60 controles del paquete y 15 de exportación. El PowerShell
exportado realizó una inferencia real y se comprobó la lectura estructural exacta
del resultado después de revocar la conexión; el fallo de igualdad del arnés se
conserva. Es evidencia fechada del candidato padre, no prueba nueva de cada build.

La traducción automática sin contexto conserva un fallo de objeto ambiguo. El
usuario confirmó el significado de tarjeta/registro de interfaz; su comprobación
posterior debe identificarse como contextualizada por una aclaración humana.
Los experimentos rechazados no se promueven ni se combinan con otros resultados.

Pendientes: aceptación pública NOVA/Companion y ChatGPT MCP, cifrado/retención y
restauración operativa privada, aceptación de horario público de 12 horas y
resultado real de instalación en VM nueva. El usuario detuvo el control del
navegador con Escape durante este corte. No se declara GO integral ni comercial.

El workflow entrega ZIP/hash e imagen versionados cuando pasan los controles; la
promoción del commit exacto se solicita explícitamente y usa el servicio existente.
No se incluyen credenciales, bibliotecas privadas ni modelos.

Traducción contextual comprobada el 02/11: tras la aclaración humana de tarjeta/registro,
una nueva captura produjo Card and instruction y Open the card «Firmar» and request
to sign <acuerdo>. Dos llamadas reales, sin retries ni efectos. El fallo automático
sin aclaración se conserva; no se declara una campaña automática 4/4.
